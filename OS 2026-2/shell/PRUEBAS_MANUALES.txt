paso 1
make -> para compilar
./sys_shell -> para ejecutar el programa y se controla desde la terminal

paso 2
Open <nombre del archivo> -> crea un archovo con ese nombre.

paso 3
Add <nombre del archivo> "lo que se le quiera agregar" -> asi se agrega una linea al archivo y toca hacerlo lina por linea o se modifica el archivo para hacerlo mas rapido

paso 4
Print <nombre del archivo> -> printea lo que esta dentro del archivo

paso 5
Zip <nombre del archivo> -> comprime el archivo y crea su version .zip (notas.txt -> notas.zip). Requiere tener instalado el programa zip (sudo apt install zip)

paso 6
Delete <nombre del archivo> # -> el numeral solo representa el numero de linea que se quiera eliminar y sin este se borra todo el archivo 
---------------------------------------------------------------------------------------------------------------------

paso 7 - COMPRESION HUFFMAN CONCURRENTE (Parcial 2)

Comprimir <archivo> [num_hilos]      -> comprime con Huffman paralelo en segundo plano y crea <archivo>.huff
Descomprimir <archivo.huff> [hilos]  -> restaura el archivo original
Tareas                               -> muestra el progreso o el resultado de las tareas

El prompt NO se bloquea: la tarea corre en sus propios hilos y el avance aparece solo.
Si intentas hacer Add o Delete sobre un archivo que una tarea esta usando, el shell lo
rechaza para no corromper el resultado (eso es el control de condiciones de carrera).

Para ver la barra de progreso hace falta un archivo grande (los pequenos terminan al
instante). Se genera uno de ~24 MB asi, desde la terminal normal:

  awk 'BEGIN{s="texto de prueba para comprimir con huffman ";for(i=0;i<500000;i++)printf "%s", s}' > grande.txt

Y para comprobar que la descompresion devuelve EXACTAMENTE el original:

  md5sum grande.txt            # anota el valor
  ./sys_shell                  # Comprimir grande.txt 8  ... luego exit
  rm grande.txt
  ./sys_shell                  # Descomprimir grande.txt.huff 8 ... luego exit
  md5sum grande.txt            # debe dar el MISMO valor

Todo lo anterior esta automatizado en un solo script:

  ./pruebas_huffman.sh
